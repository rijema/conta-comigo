## Texto potencial para a dissertação

### Metodologia

O sistema de ilhas foi projetado para cobrir progressivamente as habilidades matemáticas definidas pela BNCC (Base Nacional Comum Curricular) do 1º ao 5º ano. Cada ilha agrupa habilidades relacionadas a um tema específico, criando um contexto semântico que facilita a aprendizagem.

A distribuição de habilidades segue dois princípios:
1. **Progressão vertical:** Ilhas posteriores cobrem anos mais avançados
2. **Reforço horizontal:** Habilidades aparecem em múltiplas ilhas para consolidação

### Decisão de projeto

Optou-se por distribuir habilidades em múltiplas ilhas (em vez de uma ilha por habilidade) para:
- Permitir revisão e consolidação
- Criar contextos diferentes para a mesma habilidade
- Facilitar adaptação a diferentes níveis de aprendizado

### Limitações

- EF01MA04 e EF01MA05 não existem no banco de dados
- Cobertura de 90.5% das habilidades disponíveis
- Distribuição é estática (não se adapta dinamicamente ao progresso)

### Evidência necessária no experimento

1. **Validação de cobertura:** Confirmar que todas as habilidades são praticadas
2. **Efetividade por tema:** Medir se temas das ilhas melhoram retenção
3. **Progressão:** Verificar se progressão entre ilhas é apropriada
4. **Revisão:** Confirmar que revisão em múltiplas ilhas melhora mastery
