## 🛠️ Specs de Implementação

### A1: Cada exercício DEVE TER
```
✓ Título em português
✓ Pictogramas ARASAAC (não emoji!)
✓ Tipo de computação (selection, drag_drop, etc)
✓ Pelo menos 2 dificuldades (very_easy, easy)
✓ JSON com variações de dados (não repetir padrão v, v+2)
✓ Modality: visual E (audio OU kinesthetic) na forma mínima

❌ NUNCA:
  - Apenas texto
  - Emojis comuns (⭐, 🍎)
  - Padrão óbvio de números (2,3,4,5,6...)
  - Sem áudio em VERY_EASY
```

### A2: Integração ARASAAC

**Protocolo**:
1. Cada pictograma = conceito ARASAAC ID
2. Exemplo: `pictogramConceptId: 'library.apple'` → usa maçã real ARASAAC
3. Fonte: ARASAAC Open API (gratuita, 30mil+ pictogramas)

**Mapeamento Conta Comigo**:
```typescript
// Em activities.seed.ts, adicione:
const arasaac = {
  'apple': 'https://api.arasaac.org/v1/pictograms/id/2',
  'square': 'https://api.arasaac.org/v1/pictograms/id/4',
  'circle': 'https://api.arasaac.org/v1/pictograms/id/6',
  'number_1': 'https://api.arasaac.org/v1/pictograms/id/8',
  // ... etc
}
```

### A3: Áudio & Voz

**Fonte**: TitiA ML Service (já existe!)

**Exemplos**:
```
- "Um, dois, três..." (narração para contagem)
- "Qual tem mais?" (pergunta natural)
- "Acertou! Parabéns!" (feedback)
- "Escuta a próxima pergunta..." (transição)
```

### A4: Vídeos & GIFs

**Protocolo**: Incorporar em `content.videoUrl` / `content.gifUrl`

**Exemplos a gerar**:
```
GIF: Números 1-10 aparecendo dinamicamente
GIF: Maçãs caindo em cesta (drag feedback)
VIDEO: Explicação de "maior/menor" com ARASAAC
VIDEO: Criança contando (inspiração para aprender)
```

## 🎯 Checklist de Qualidade

Para cada exercício criado:

```
Semântica:
- [ ] Alinha com EF (um skill específico da BNCC)
- [ ] Conhecimento prévio necessário ≤ escopo

Interação:
- [ ] Tipo computacional bem definido
- [ ] Feedback claro (acertou/errou)
- [ ] Não exige leitura pesada (máx 10 palavras)

Acessibilidade:
- [ ] ARASAAC para cada conceito visual
- [ ] Áudio + texto (redundância)
- [ ] Contraste suficiente
- [ ] Toque não ultrapassa 44px

Dinâmica:
- [ ] Tem animação? (GIF/vídeo)
- [ ] Tem áudio? (voz ou feedback sonoro)
- [ ] Tem movimento? (drag, construção)
- [ ] NÃO é estático+texto

Dados:
- [ ] 5+ variações de números (não padrão)
- [ ] Contempla casos extremos (0, 10, ordem invertida)
- [ ] Sem "pistas visuais" óbvias que facilitam

Testes:
- [ ] Criança consegue fazer em <3 minutos
- [ ] Sem erros óbvios na UI
- [ ] Áudio inteligível
- [ ] Sem lags em tablet/smartphone
```
